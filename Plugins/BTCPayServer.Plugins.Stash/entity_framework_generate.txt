Entity Framework Migrations for Stash Plugin
=============================================

To generate EF migrations for this plugin, run these commands from the plugin directory:

# Initial migration:
dotnet ef migrations add InitialCreate --context PluginDbContext

# After making model changes:
dotnet ef migrations add <MigrationName> --context PluginDbContext

# To apply migrations (typically done automatically on startup):
dotnet ef database update --context PluginDbContext

Note: Migrations are automatically applied when the plugin starts via PluginMigrationRunner.
